# Homepage

This is my personal website.
A small static site showcasing me and my projects.

Stack:
 - Astro
 - Custom CSS

# Usage

Requires Node.js 22.12 or newer.

**For development**

```bash
npm install
npm run dev
```

**For production**

```bash
npm run build
```

The static output in `dist/` is served by nginx, see `deploy/nginx.conf`.
